# Ayrton Senna – Lenda do Automobilismo

Site em homenagem a Ayrton Senna, com a trajetória do piloto, galeria de fotos, vídeo, tabela de títulos e poles, formulário de contato e fontes de pesquisa.

> **Este foi meu primeiro projeto de front-end.** Foi minha primeira interação com desenvolvimento web, e aprendi muito construindo cada página.

##  Acesse o site

O projeto está publicado com o **GitHub Pages**:

 **https://gustazlx.github.io/Primeiro-projeto/**

## Páginas

| Página | Conteúdo |
|--------|----------|
| `index.html` | Página inicial com apresentação e atalhos para as demais seções |
| `biografia.html` | Vida e carreira de Senna, dividida em seções |
| `midias.html` | Galeria de imagens e vídeo "A Vontade de Vencer" |
| `titulos.html` | Tabela de títulos mundiais e poles por ano |
| `contato.html` | Formulário de contato |
| `fontes.html` | Fontes utilizadas na pesquisa |

## Tecnologias

- HTML5
- CSS3
- Bootstrap 5
- GitHub Pages (publicação)
